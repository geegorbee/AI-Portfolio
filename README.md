## 🤖 Featured Projects

### [LLM Prompt Evaluator](https://github.com/geegorbee/LLM-Prompt-Evaluator)

**Built:** June 2024 (6+ months ago)  
**Status:** Functional, actively maintained

AI-powered tool that evaluates and grades the quality of prompts for Large Language Models using GPT-4 analysis.

**What it does:**
- Analyzes prompts for clarity, specificity, and context
- Provides quality scores and improvement suggestions
- Helps identify weak prompts that may be vulnerable to issues
- Serves as a meta-AI tool (using AI to improve AI interactions)

**Technical Stack:**
- OpenAI GPT-4 API
- Python
- Prompt engineering patterns

**Key Learning:**
- Prompt quality directly impacts AI output reliability
- Understanding what makes prompts effective vs. vulnerable
- API integration and error handling
- Iterative improvement based on AI feedback

**Security Implications:**
Weak prompts create security risks in AI systems. This tool helps identify prompt weaknesses before deployment. [See security analysis →](../Cybersecurity-Portfolio/AI-Security/)
